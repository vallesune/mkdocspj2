La llicencia Retail es de les mes comuns junt la "OEM" i es una llicencia no lligada al hardware que per tant permet transferirla a un altre equip si es necessita. Totes les llicencies de Windows son de tipus software de propietari, per tant els usuaris unicament adquereix un dret d'us no la propietat i no son de software lliure com les de linux.

## Comandes generals

Cmd es una terminal de windows pensada per comandes mes basiques en canvi powershell es mes potent i te opcions d'automatitzacio 

Obrim cmd per provar algunes comandes basiques:

dir
cd
mkdir prova
echo hola > fitxer.txt
del fitxer.txt

Comandes del sistema

tasklist(explicar)

taskkill /IM notepad.exe /F (tancar proces)

systeminfo (explicar)

hostname
whoami

Comandes de xarxa

ipconfig (explicar)
ping google.com
netstat -an

Comandes interesants

tree
cls(netejar pantalla)
help
shutdown /s /t 0(apagar l’equip)
